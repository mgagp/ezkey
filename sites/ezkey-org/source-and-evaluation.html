About the community instance

Run locally

  1. Clone the public repository github.com/mgagp/ezkey, then follow the Quick Start in the README.
  2. Run the clean start The supported developer stack path is a Bash script. On Windows, use Git Bash. 
    ./ezkey-tests/clean-start.sh
  3. Go further Further notes live under ezkey-tests/README.md and docker/README.md in the repository.

Prefer not to run a stack? Try the community instance on ezkey.online.
