Source code & evaluation

Ezkey is intended to ship as open source under the MIT License. The main repository is private for now and is planned to open publicly around September 2026 with the first official release, alongside in-repo documentation and supported local setup (see Product updates for the current timeline).

This page replaces public GitHub links until the repository is readable without authentication.

Documentation

Canonical technical documentation (architecture, APIs, configuration, operations) lives in the repository. While the repository stays private, this site publishes API Docs, Product updates, and Articles & notes for progress and selected technical context — not a full substitute for the in-repo docs.

Run locally

The supported developer workflow (including clean start) is maintained inside the private repository. Those instructions will be linked from ezkey.org once the repository is public.

If you are evaluating the technology preview, program context and constraints are described in Exp1 preview — limited access.

Security contact

For suspected vulnerabilities, use security@ezkey.org. Do not rely on public issue trackers until a published security policy ships with the public repository.
