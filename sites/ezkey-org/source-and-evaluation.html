Source code & evaluation

Ezkey is open source under the MIT License. The main repository is public on GitHub: https://github.com/mgagp/ezkey.

The project remains alpha — not production-ready. There are no published release packages yet (no GitHub Releases or installable binaries to consume). Evaluate the source, the docs, a local stack, or the live community instance; do not treat Ezkey as a drop-in replacement for Duo, Okta, or Keycloak.

Documentation

Canonical technical documentation (architecture, APIs, configuration, operations) lives in the repository — start from the README Documentation section and the in-repo docs/ tree. This site publishes API Docs, community pages, Monthly digests, and Articles & notes as evaluation aids — not a full substitute for the in-repo docs.

Run locally

Clone the public repository and follow the Quick Start in the README. The supported developer stack path is the Bash clean start:

./ezkey-tests/clean-start.sh

Further notes live under ezkey-tests/README.md and docker/README.md in the repo. On Windows, use Git Bash.

If you prefer a live alpha evaluation without standing up a stack, use the community instance on ezkey.online — see Community instance — alpha on ezkey.online.

Security contact

For suspected vulnerabilities, use security@ezkey.org. The project’s SECURITY.md policy lives in the public repository; the email remains valid either way. Do not use public GitHub issues for vulnerability reports.
