Integration API reference

The Integration API is the machine-to-machine contract surface for auth attempt lifecycle operations. It is part of the public documentation group, while still remaining optional by deployment.

  • Public posture: read-only documentation reference.
  • Static OpenAPI asset: integration-api-openapi.json.
  • Some Ezkey deployments may omit this API entirely; that optionality is operational, not a documentation error.
