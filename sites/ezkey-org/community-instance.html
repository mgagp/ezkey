Your role: tenant administrator

Administration has two levels: global (the whole instance) and tenant (one organization). On the community instance, you act as a tenant administrator, which is enough for the Acme demo, enrollments, and authentication with the mobile app or the Demo Device.

Ezkey supports other enrollment paths (including QR and recovery); here, the documented path is the activation code.

Before you start

  • Alpha, not production: no production SLA.
  • Ezkey is not Duo / Okta / Keycloak parity, and not WebAuthn / FIDO2 / passkey equivalence.
  • The community host runs the integrity profile by default (audit-trail integrity checks on); base is an opt-in profile for limited claims, not an “eval-by-default” posture.
  • Mobile: Android only in this milestone; no iOS release date announced. The app does not yet have the full hardening of a shipping production release. Local secret storage is already strengthened; app-open locking (biometrics or an equivalent strong mechanism) is on the roadmap. If it is missing or partial here, treat that as a transitional state, not the final model.
