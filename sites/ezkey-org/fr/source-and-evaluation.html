Code source et évaluation

Ezkey est open source sous licence MIT, et le dépôt principal est public sur GitHub. Évaluez le code et la documentation, exécutez la stack vous-même, ou essayez l’instance communautaire en ligne.

Ouvrir le dépôt sur GitHub Essayer l’instance communautaire
Alpha

Pas prêt pour la production, et pas encore de paquets de version publiés (ni GitHub Releases ni binaires installables). Ezkey n’est pas un substitut à Duo, Okta ou Keycloak.

Alpha · ezkey.online Instance communautaire

Une évaluation alpha en ligne sans monter de stack : accès limité, parcours guidé.

À propos de l’instance communautaire

Exécuter en local

  1. Cloner le dépôt public github.com/mgagp/ezkey, puis suivre le Quick Start du README.
  2. Lancer le clean start Le chemin stack développeur supporté est un script Bash. Sous Windows, utilisez Git Bash. 
    ./ezkey-tests/clean-start.sh
  3. Aller plus loin Des notes complémentaires figurent dans ezkey-tests/README.md et docker/README.md du dépôt.

Vous préférez ne pas monter de stack ? Essayez l’instance communautaire sur ezkey.online.
