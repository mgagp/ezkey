Code source et évaluation

Ezkey est prévu pour être publié en open source sous licence MIT. Le dépôt principal est privé pour l’instant ; l’ouverture publique est prévue vers septembre 2026 avec la première version officielle, en même temps que la documentation dans le dépôt et la procédure locale supportée (voir les Sommaires mensuels pour l’échéancier actuel).

Cette page remplace les liens GitHub publics tant que le dépôt n’est pas accessible sans authentification.

Documentation

La documentation technique de référence (architecture, APIs, configuration, exploitation) vit dans le dépôt. Pendant que le dépôt reste privé, ce site publie la Documentation API, des Sommaires mensuels et des Articles et notes sur l’avancement et un contexte technique sélectif — ce n’est pas un substitut complet aux documents dans le dépôt.

Exécuter en local

Le flux développeur supporté (y compris le clean start) est maintenu dans le dépôt privé. Les instructions seront reliées depuis ezkey.org une fois le dépôt public.

Si vous évaluez l’instance communautaire alpha sur ezkey.online, le cadrage et les limites d’honnêteté sont décrits dans Instance communautaire — alpha sur ezkey.online.

Contact sécurité

Pour une vulnérabilité présumée, utilisez security@ezkey.org. N’utilisez pas de tickets publics tant qu’une politique de sécurité publiée n’accompagne pas le dépôt ouvert.
