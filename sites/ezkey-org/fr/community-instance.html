Instance communautaire — essayer Ezkey en alpha

Ezkey est un produit en alpha. Le site produit reste sur ezkey.org. Une instance communautaire maintenue tourne sur ezkey.online pour que les évaluateurs puissent essayer la pile en direct, sans prétendre offrir une solution de production.

Limites d’honnêteté. L’alpha n’est pas un SLA de production. Ezkey n’est pas une parité Duo / Okta / Keycloak. Ezkey n’est pas une équivalence WebAuthn / FIDO2 / passkey. Le profil d’exécution par défaut sur l’hôte communautaire est integrity ; base est un profil optionnel pour des revendications limitées — pas une posture « évaluation par défaut ».

À qui s’adresse ceci, et comment demander l’accès

Les invitations directes passent en premier, ciblées (ingénierie, produit, presse spécialisée).

Accès communautaire instantané (places limitées par jour) : lorsque la fonctionnalité est activée sur l’instance communautaire, vous pouvez demander un espace immédiatement et recevoir un code d’activation sur place — sans courriel pour ce chemin. Les places sont plafonnées ; si la capacité est atteinte, réessayez plus tard ou utilisez le courriel ci-dessous. Page d’inscription en anglais.

Vous n’avez pas été invité·e mais souhaitez un accès examiné ? Écrivez à info@ezkey.org en quelques phrases : qui vous êtes et ce que vous voulez valider. L’accès n’est pas ouvert à tous : la capacité est limitée et chaque demande est revue ; une réponse n’est pas garantie.

Ce que vous pouvez utiliser sur ezkey.online

Un déploiement tout-en-un prévu pour un faible volume et l’évaluation — pas pour la charge ni les assurances d’un environnement de production.

  • Ezkey Demo Device — téléphone simulé (projet GitHub public) pour remplacer l’app mobile pendant l’évaluation : github.com/mgagp/ezkey-demo-device
  • Application mobile Ezkey (Android) — préversion early-adopter ; encore en test interne limité, pas le chemin par défaut pour les évaluateurs anonymes.
  • Administration (périmètre locataire) — admin-ui.ezkey.online
  • Démo d’intégration « Acme » — demo-acme.ezkey.online
  • Admin API — admin-api.ezkey.online (et des noms d’hôte parallèles Auth / Integration sur le même domaine lorsque l’outillage le demande)

Android uniquement à ce jalon. iOS : aucune date de publication annoncée.

L’application mobile n’a pas encore le durcissement attendu d’une version de production livrée. Le chemin de référence Android a déjà renforcé le stockage local des secrets, mais le durcissement opérationnel plus large reste incomplet. Le verrouillage à l’ouverture de l’app (biométrie ou mécanisme fort équivalent, niveaux de contrôle encore à préciser) est prévu sur la feuille de route ; s’il est absent ou partiel sur l’instance communautaire, traitez cela comme un état transitoire, pas le modèle final.

Accès : code d’activation et rôle d’administrateur de locataire

Après acceptation d’une demande (ou d’une invitation), un code d’activation est envoyé par courriel ; en pratique, comptez jusqu’à environ deux jours ouvrables. Le chemin d’inscription instantanée affiche le code immédiatement lorsque des places sont disponibles.

Ezkey prend en charge d’autres chemins d’enrôlement dans l’écosystème (dont QR et récupération) ; ici, le chemin documenté est le code d’activation.

L’administration a deux niveaux : global (toute l’instance) et locataire (une organisation). Sur l’instance communautaire, vous agissez comme administrateur de locataire — suffisant pour la démo Acme, les enrôlements et l’authentification avec l’app mobile ou le Demo Device.

Retours et confidentialité

Retours (parcours, bogues, idées) : info@ezkey.org. Sujets couverts par la politique produit : voir la politique de confidentialité.

Suite

Suivez le parcours guidé illustré (Admin UI, code d’activation, enrôlement, démo Acme) une fois que vous avez un code d’activation.
