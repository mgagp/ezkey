Votre rôle : administrateur de locataire

L’administration a deux niveaux : global (toute l’instance) et locataire (une organisation). Sur l’instance communautaire, vous agissez comme administrateur de locataire, ce qui suffit pour la démo Acme, les enrôlements et l’authentification avec l’app mobile ou le Demo Device.

Ezkey prend en charge d’autres chemins d’enrôlement (dont QR et récupération) ; ici, le chemin documenté est le code d’activation.

Avant de commencer

  • Alpha, pas production : pas de SLA de production.
  • Ezkey n’est pas une parité Duo / Okta / Keycloak, ni une équivalence WebAuthn / FIDO2 / passkey.
  • L’hôte communautaire tourne avec le profil integrity par défaut (contrôles d’intégrité du journal d’audit actifs) ; base est un profil optionnel pour des revendications limitées, pas une posture « évaluation par défaut ».
  • Mobile : Android uniquement à ce jalon ; aucune date annoncée pour iOS. L’app n’a pas encore le durcissement complet d’une version de production livrée. Le stockage local des secrets est déjà renforcé ; le verrouillage à l’ouverture (biométrie ou mécanisme fort équivalent) est prévu sur la feuille de route. S’il est absent ou partiel ici, traitez cela comme un état transitoire, pas le modèle final.

Suite : trois étapes

  1. Obtenir un code d’activation Inscription instantanée lorsque des places sont disponibles, ou par courriel après examen.
  2. Vous connecter à l’Admin UI avec ce code admin-ui.ezkey.online, comme administrateur de locataire.
  3. Suivre le parcours guidé Le parcours illustré couvre l’enrôlement et la démo Acme, jusqu’à une connexion réussie.
