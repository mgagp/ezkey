Septembre 2026 en revue

Alpha publique honnête, intégrité que les opérateurs peuvent examiner

Septembre a ouvert Ezkey en alpha publique qu'on peut essayer, a nommé les limites sans maquillage, et a donné aux admins globaux un moyen de premier plan de surveiller l'intégrité de la piste d'audit.

En bref

Ezkey a cessé de sonner comme une expérience de labo interne et a commencé à parler en alpha publique : code sous MIT, instance communautaire sur ezkey.online, et un langage clair — travail de laboratoire, sans SLA, sans promesse de production, et sans équivalence Duo, Okta ou Keycloak. Une grande part de l'énergie du mois a servi à faire tenir cette honnêteté sur le site et dans les outils opérateur. Les admins globaux disposent désormais d'une surface Intégrité dédiée pour examiner le matériel d'audit scellé sans chercher dans des chemins latéraux. L'hygiène et le triage des dépendances ont maintenu la stack à jour sans devenir le récit principal.

Documentation & méthodologie

L'équipe a refermé le cadrage « mise en service opérationnelle » et a nommé ce qui est réellement en ligne : une alpha publique discrète, Android en tests fermés seulement, et l'inscription évaluateur désactivée par défaut. Les textes produit et ezkey.org ont laissé tomber les anciens noms d'hôtes de labo au profit d'un langage communauté alpha, avec une traçabilité de version et de déploiement pour que le lecteur voie ce qui tourne. Un essai craft sur le pilotage par intention a été publié, avec un schéma plus léger de durcissement de plan en deux étapes pour les changements à risque. Des notes à plus long horizon, encore en cours, cartographient la posture post-quantique du protocole et le comportement attendu des enrôlements quand les identités sont réutilisées.

Hygiène de code

Le triage hebdomadaire des dépendances s'est poursuivi sur la stack Java, la console d'administration, le mobile et le SDK. Le mobile est passé à une ligne React Native plus récente ; les pins de génération de clients et d'outillage sont restés alignés entre surfaces. Les passes d'analyse statique curatées et les habitudes Dependabot ont gardé la maintenance visible sans transformer le mois en journal de mises à niveau.

Admin UI

L'Intégrité est passée d'une préoccupation latérale à une destination de premier plan pour l'admin global : modes plus clairs, divulgation progressive, et libellés honnêtes quand une installation tourne sans surveillance d'intégrité complète. Les travaux longs de scellement et d'investigation peuvent s'exécuter sans geler la console. Les admins de tenant voient le nom de leur tenant dans l'en-tête. Les échecs de connexion sans mot de passe n'impliquent plus qu'un mot de passe était erroné. En cours : une console évaluateur temporaire pour explorer l'Admin UI pendant une fenêtre bornée sans enrôler d'abord un appareil — toujours verrouillée et désactivée par défaut.

Application mobile

React Native a avancé ; les textes des Réglages ont été réécrits pour l'utilisateur final ; l'accueil peut regrouper les enrôlements dans une grille d'identité plus claire. Les builds de tests fermés portent l'étiquette alpha publique pour que les testeurs Play ne reçoivent pas une histoire de production. Reste ouvert : ce qui se passe quand un admin supprime puis recrée un enrôlement alors que le téléphone conserve encore l'ancienne liaison locale — constaté comme cas limite alpha, pas encore corrigé produit.

Backend & contrats d'API

Les grants de moindre privilege en base ont été resserrés ; la mise à jour automatique de schéma est restée désactivée sur les API en exécution. Les sessions d'attente sans mot de passe ont été durcies contre la relecture et le détournement de session. La rotation de clés inactive et la validation d'intégrité échouent en fermeture stricte quand continuer affaiblirait silencieusement la garantie. Les sondages de sécurité se sont approfondis avec des correctifs de limitation de débit et de méthodes HTTP. Les spécifications OpenAPI ont été rafraîchies pour la bordure publique, y compris l'empaquetage Cloudflare Schema Validation pour l'hôte communautaire.

Le reste, digne de mention

  • Ops communautaires : chemin d'amorçage Lightsail, routage Caddy et empaquetage de schémas Cloudflare pour lever et tenir ezkey.online comme hôte communauté alpha — sans promesse de production.
  • Module SSH MFA labo seulement : hygiène et constructeur Amazon Linux pour dogfood interne ; explicitement hors du parcours alpha publique.
  • Revue d'isolation en boîte blanche : regard curaté sur le respect des frontières de tenant dans le SQL des services — constats enregistrés pour remédiations ultérieures, pas tacitement tenus pour résolus.
  • SDK et outillage agent : builds du client JavaScript débloqués sur TypeScript actuel ; les environnements Cloud Agent ont gagné une stack locale plus complète pour que la revue parte plus près du réel.

Août visait un septembre opérationnel. Ce qui a atterri est plus clair : une alpha publique aux bornes honnêtes, une Intégrité que les opérateurs peuvent examiner, et une communauté qu'on peut essayer — sans prétendre que le produit est terminé. L'attention suivante porte sur un accès évaluateur qui reste temporaire et honnête, sur les aspérités alpha évidentes du mobile, et sur un visage public aligné avec ce que la stack fait vraiment.
