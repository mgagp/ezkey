Préversion exp1

Préversion technologique exp1 — instance expérimentale et invitations

Ezkey ouvre une préversion technologique sur une instance publique exp1 : c’est une expérimentation, pas une offre de production. L’ambition est simple — faire essayer le système à un nombre limité de personnes, recueillir des retours concrets et stabiliser le produit d’ici l’ouverture du dépôt annoncée pour septembre 2026 (sous réserve du travail de fin de préversion).

Qui est concerné, comment demander l’accès

Priorité aux invitations directes adressées à des profils ciblés (technique, produit, presse spécialisée).

Accès instantané (places limitées par jour) : lorsque la fonctionnalité est activée sur exp1, vous pouvez demander un espace d’évaluation immédiatement et recevoir un code d’activation sur place — sans courriel pour ce chemin. Les places sont plafonnées ; si la capacité est atteinte, réessayez plus tard ou utilisez le courriel ci-dessous.

Vous n’avez pas été invité·e mais souhaitez un accès examiné manuellement ? Écrivez à info@ezkey.org en quelques phrases : qui vous êtes, ce que vous voulez vérifier. L’accès n’est pas généralisé : la capacité est faible et chaque demande est examinée ; une réponse n’est pas garantie.

Ce que vous pouvez utiliser sur exp1

Déploiement tout-en-un, prévu pour peu de monde et l’évaluation — pas pour la charge ni les garanties d’un environnement de production.

  • Ezkey Demo Device — téléphone simulé (projet public sur GitHub) pour remplacer l’app mobile pendant l’évaluation : github.com/mgagp/ezkey-demo-device
  • Application mobile Ezkey (Android) — préversion pour premiers adopteurs ; encore en test interne limité, pas le chemin par défaut pour les évaluateurs anonymes.
  • Administration (périmètre locataire) — exp1-admin-ui.ezkey.org
  • Démo d’intégration « Acme » — exp1-demo-acme.ezkey.org

Android seulement pour cette phase. iOS : pas de date annoncée.

L’app mobile n’a pas encore le niveau complet de durcissement attendu d’une release opérationnelle finale. Le chemin de référence Android a déjà renforcé la protection du stockage local des secrets, mais le durcissement opérationnel plus large reste encore incomplet. Le verrou à l’ouverture (biométrie ou équivalent fort, avec des niveaux de contrôle à préciser) est prévu prochainement sur la feuille de route ; si ce n’est pas encore là ou encore partiel, voyez-le comme un état transitoire, pas comme le modèle définitif.

Accès : code d’activation, rôle « administrateur de locataire »

Après acceptation d’une demande (ou d’une invitation), un code d’activation est envoyé par courriel ; en pratique, comptez jusqu’à environ deux jours ouvrables. Le chemin instantané affiche le code immédiatement lorsque des places sont disponibles.

Ezkey prévoit d’autres modes d’enrôlement (dont QR et récupération) dans l’écosystème ; ici, le chemin documenté est le code d’activation.

À l’administration, il existe deux niveaux : global (instance entière) et locataire (une organisation). Sur exp1, vous agissez en administrateur de locataire — assez pour la démo Acme, les inscriptions et l’authentification avec le mobile.

Retours et confidentialité

Retours (parcours, bugs, idées) : info@ezkey.org. Questions couvertes par la politique du produit : voir politique de confidentialité.
