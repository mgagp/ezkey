Référence Auth API

L’Auth API porte les flux backend-vers-mobile pour l’inscription et l’authentification. C’est la surface de contrat côté terminal mobile pour la récupération des requêtes en attente, la soumission des réponses et les opérations de cycle de vie du terminal.

  • Posture publique : référence documentaire en lecture seule.
  • Actif OpenAPI statique : auth-api-openapi.json.
  • Le portail public est le point d’entrée documentaire voulu pour une exposition de type production, pas les outils Swagger runtime publics.
