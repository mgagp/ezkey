Ezkey API Docs

This portal is the public read-only reference for the Ezkey API group. It is meant for evaluators, integrators, and technical readers who want the contract surface without exposing live runtime Swagger tooling on production-like hosts.

The public group includes the Admin API, Auth API, and the optional Integration API. The Crypto API remains outside the public documentation posture.
