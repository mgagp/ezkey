Instant community access (limited daily slots)

When slots are available, you can create a private workspace on the ezkey.online community instance (Ezkey alpha) and receive a one-time activation code immediately — no email required for this path.

Save your activation code. It is shown once on this page. Copy it somewhere safe before you leave. You will use it on the Admin UI sign-in screen, then follow the guided tour.

Prefer a reviewed invitation or have questions? Email info@ezkey.org instead — see the community instance overview. Alpha is not a production SLA.
