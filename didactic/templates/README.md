# Didactic template catalog

Use template slugs through `./render-example.sh`, or pass the paths directly to `python -m protocol_lab render`.

| Slug | Path | Purpose |
| --- | --- | --- |
| `access-login-full` | `templates/access-login/article-full.md` | Default technical walkthrough: user approves sign-in or access to an integration. |
| `contextual-approval-full` | `templates/contextual-approval/article-full.md` | Variant that leans into richer business context copy on the pending request. |
| `trace-index` | `templates/shared/trace-index.md` | Compact companion index for the same artifact bundle. |

The recommended default for technical article drafting is `access-login-full`.
