🔐 SESSION & AUTH FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FIRST RUN:
  ezkey --tui
    ↓
  LoginWizard:
    • Enter Admin API URL
    • Enter username
    • Enter organization
    • Approve on device (challenge code shown)
    • Session created & encrypted
    ↓
  Dashboard loads

SUBSEQUENT RUNS:
  ezkey --tui
    ↓
  Load session from ~/.ezkey/admin/session
    ↓
  Refresh token if needed (silently)
    ↓
  Dashboard loads immediately
