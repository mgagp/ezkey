HOW THIS LOGIN WORKS

This demo application uses backend-side authentication. The server securely communicates with the EZKey Admin API using API Key Machine-to-Machine (M2M) authentication. All authentication logic runs server-side, ensuring tokens and credentials never reach the browser.

KEY FEATURES

  • Server-side authentication (secure)
  • HTTP session management
  • API Key M2M authentication
  • No CORS configuration needed
  • Traditional MVC approach

Security Note: All EZKey API communication happens server-side using API Key credentials. The browser only receives session cookies, ensuring that sensitive authentication tokens are never exposed to client-side code.
