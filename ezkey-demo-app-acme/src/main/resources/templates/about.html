About ACME Demo

Ezkey Integration Showcase

Purpose

This demo application simulates a real-world enterprise application (ACME Inc) that integrates with Ezkey MFA for secure user authentication.

Technology Stack

Backend

  • Spring Boot 3.3.6
  • Java 21
  • Thymeleaf Templates
  • WebFlux HTTP Client

Frontend

  • htmx for Dynamic Interactions
  • Alpine.js for Reactivity
  • Neo Brutalism UI Design
  • Responsive CSS Grid

Demo Features

01

Integration Management

Create and manage Ezkey integrations for your applications.

02

Device Enrollment

Enroll mobile devices for secure multi-factor authentication.

03

Authentication Testing

Test authentication flows with simulation mode capabilities.
