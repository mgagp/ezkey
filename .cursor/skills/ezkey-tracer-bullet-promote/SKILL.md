# Ezkey Tracer Bullet Promote

## Purpose

Turn a `ready` idea into a validated first vertical slice (`TB-*`).

## Inputs

- `I-*` idea
- Current risk and scope understanding

## Outputs

- `TB-*` brief
- In-scope boundaries
- Out-of-scope boundaries
- Acceptance evidence plan
- Initial test-layer plan link

## Steps

1. Define the smallest meaningful end-to-end slice.
2. Identify touched component boundaries.
3. Define critical nominal and exception path.
4. Define expected evidence (tests, docs, traceability).
5. Mark explicit exclusions for this slice.

## Rule

Favor one deep vertical over broad partial coverage.
