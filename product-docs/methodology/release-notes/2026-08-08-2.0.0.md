# Methodology Release — 2.0.0 (2026-08-08)

## Metadata

- **Version:** 2.0.0 (SemVer)
- **Released:** 2026-08-08
- **Previous version:** 1.2.0
- **Bump level:** major

## Summary

Radical ablation of the methodology corpus: roughly 93% of it was deleted in one deliberate pass,
following the principle of deleting first and watching what a cold agent actually needs. The whole
method now fits in one core document ([`../README.md`](../README.md)), four templates, and the
glossary. The public site was rebuilt around that smallness: one guided reading track, no skills
layer, no workflow map, no rich view. Prior guidance that no longer appears in the core document no
longer applies.

The full before/after record, including everything that was cut and why, is
[`2026-08-08-ablation-record.md`](2026-08-08-ablation-record.md).

## Breaking changes

Almost everything, by design:

- 21 method documents reduced to **one** core README (posture, documentary levels, bidirectional
  discoverability, values compass, three surviving rules).
- 20 templates reduced to **4**: `vision-note`, `backlog-idea`, `tracer-bullet-brief`,
  `architecture-decision`.
- All 32 dated methodology decision records deleted; surviving lessons were folded into the core
  document. Git history is the archive — no `archive/` folder.
- The 14-skill public layer is gone. Workflow phases, guided persona tracks (Start / Discover /
  Apply / Present), the cognitive workflow map, and the rich HTML view are gone as mechanisms, not
  just as content.
- The download pack no longer ships editor-local skill files; it contains the corpus itself.

## What survives

- **Documentary levels** — `V-*`, `I-*`, `TB-*`, `ADR-*`, each with its lifecycle.
- **Bidirectional discoverability** — enough metadata that a cold agent can resume from the corpus
  alone.
- **The values compass** — proportional rigor, 80/20 simplicity, essential vs. accidental
  complexity, one canonical place per concept, fail-open vs. fail-closed, stay in the stack.
- **Three rules** that real sessions kept needing: hygiene vs. program, ephemeral scaffold vs.
  retained plan, closed uncertainty stays closed.

## Adoption note

Treat 2.0.0 as a re-read, not a migration: the core document takes minutes to read. If a practice
you relied on from 1.x is not in it, that practice is no longer part of the method — IDE/agent
Plan mode is expected to carry the research, challenge, and comparison work the deleted documents
used to script.
