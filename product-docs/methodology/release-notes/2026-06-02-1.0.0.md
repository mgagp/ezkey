## Summary

First formally versioned release of the Ezkey Methodology product. Establishes independent SemVer,
release notes, a publication workflow, and visible version labeling on the public explorer. The
methodology content itself reflects the corpus already published on `methodology.ezkey.org` through
Phase 4 of the site pipeline.

## Highlights

- Canonical version in `product-docs/methodology-version.properties`
- Publication and SemVer guide: `methodology-publication-and-versioning.md`
- Release notes section on the public explorer (this folder)
- `methodology-release` skill for classifying bumps and drafting notes
- Version badge in the explorer top bar
