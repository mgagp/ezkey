# Release Notes

Published snapshots of the Ezkey Methodology product. Each note corresponds to one SemVer bump and
one deployment of `methodology.ezkey.org`.

The current version is declared in
[`methodology-version.properties`](../../methodology-version.properties).

## How to read these notes

- **MAJOR** — review carefully; prior guidance may no longer apply.
- **MINOR** — new capability; existing workflows remain valid.
- **PATCH** — clarifications and fixes; no workflow change expected.

For the publication workflow, see
[`methodology-publication-and-versioning.md`](../methodology-publication-and-versioning.md).
