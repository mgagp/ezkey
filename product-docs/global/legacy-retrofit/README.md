# Legacy Retrofit

This folder tracks structured retrofit of historical plans into canonical product-docs destinations.

## Purpose

Provide a discoverable bridge between:

- historical plan archives and ad hoc implementation history,
- current canonical product documentation.

## Contents

- `index.md` — retrofit register and status overview.
- `R-*.md` files — individual retrofit slices.

## ID convention

Use `R-YYYY-MM-DD-<slug>` for new retrofit slices. Legacy `R-YYYY-NNNN` slices remain valid
history and are not renamed.

## Workflow

Follow `../../methodology/legacy-retrofit-workflow.md`.
