# Product Vision

## Purpose

This document captures the evolving product orientation for Ezkey in a concise and practical form.

It complements the PRD by expressing directional intent and strategic emphasis over time.

## Current orientation

- Keep Ezkey backend-first and cryptographically explicit.
- Keep operator workflows pragmatic and reliable.
- Strengthen adoption through clear integration boundaries and documentation quality.
- Improve end-to-end coherence between APIs, UI flows, and mobile behavior.

## Strategic themes

- **Protocol clarity**: preserve distinct Ezkey identity and trust boundaries.
- **Operability**: reduce cognitive load for Global Admin and Tenant Admin workflows.
- **Distribution**: improve integration and SDK/CLI adoption paths.
- **Assurance**: increase traceability and quality discipline without heavy process.

## Evolution rule

When this orientation changes materially:

- update this document,
- update roadmap and feature catalog where relevant,
- create or supersede decision records when architectural consequences exist.
