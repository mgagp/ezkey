## Rationale (short)

### 1 — no-impure-state-updater

Tool attributed “impure state updater” / nested `setX` to event handlers and mutation `onSuccess`
paths (session save + `setSession`, timezone write + `setModeState`, paired pagination resets,
recovery-code toasts). No true `setState(prev => { sideEffect; return next })` pattern found.
Suppress avoids a witch-hunt; keep intentional React 18/19-friendly handler patterns.

### 2 — prefer-html-dialog

Real a11y signal (native focus trap / Escape / backdrop) but structural design cost on the shared
neo-brutal `Dialog` shell and peer overlays. Wrong lane for punctual polish. Captured as
`I-2026-07-14-admin-ui-native-html-dialog` (`triaged`, P2). Rule left unsuppressed so shortlists
keep reminding until a TB lands.

### 3 — js-hoist-intl

Flagged `new Intl.DateTimeFormat` sites sit inside cache-miss helpers (`Map` per timezone / options).
Already the recommended pattern. Skip.

### 4 — js-set-map-lookups

`includes` over small reconcile ack ids and page rows. Micropessimization without operator-visible
value. Skip (anti–diminishing-returns).

### 5 — no-event-handler

Large `useEffect` keeps audit-log filters and investigation query params in sync for deep links.
Moving that only into every filter event handler is a plumbing redesign, not a hygiene allotment.
Skip.
