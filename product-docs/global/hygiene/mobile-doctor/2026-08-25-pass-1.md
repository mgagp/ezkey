## Rationale (short)

### 1 — `ezkey-js-sensitive-console-logging`

Go on **A** (2026-08-25). The hit is `console.warn('[instanceInfo] Instance-info signature verification failed')` — operational prose, no dumped token/signature/key. The current `pattern-regex` matches the substring `signature` anywhere on the `console.*` line. Retarget the rule at logging the identifiers themselves (arguments or `${…}` interpolation). Leave the log message as-is. Kotlin sibling regex is out of this item unless the operator widens.

### 2 — `async-await-in-loop`

Skip (operator 2026-08-25, option A). Sequential await is intentional: instance-info refresh isolates fail-open/fail-closed per installation; storage hydrate isolates MOB-015 broken rows and talks to the native seal/Keystore path. Diagnosis is correct, code is not broken. Do not `Promise.all`. Add `pathFragment` suppressions for `useEnrollments.ts` and `enrollmentStorage.ts` so the next pass does not re-triage the same two sites; keep the rule for other files.

### 3 — `rn-no-metro-babel-runtime-version`

Skip (operator 2026-08-25, GO = skip). RN 0.86.2 already turns on `@babel/plugin-transform-runtime` unless `enableBabelRuntime === false`. The doctor wants a *string* version so the plugin does not assume helpers as of 7.0.0. `@babel/runtime` is already pinned at 8.0.0 in package.json. Explicit `{enableBabelRuntime: '8.0.0'}` is a compiler hint, not a second pin of the library; deferred because Babel 8 + Metro is a sensitive surface and there is no measured bundle defect. Suppress the rule.

### 4 — `no-unowned-async-error-clear`

Skip (operator 2026-08-25, GO = skip). Stale overlapping `loadPendingAttempt` can let an older `finally` clear `loading` (and theoretically race error state) while a newer load is in flight. Real pattern, rare in this UI (enrollment change / double refresh). Pending-auth path: no generation-counter rewrite without an observed race. Path-scoped suppression for `usePendingAuth.ts`.

### 5 — `NewLineAtEndOfFile`

Fix (operator 2026-08-25, GO = fix). Missing POSIX newline at EOF on `SealedSecretEnvelope.kt` and its test. Style/Git only; no crypto change.
