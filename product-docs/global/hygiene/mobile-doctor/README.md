# Mobile doctor-curated — campaign notes

Lightweight HITL decision track for punctual `mobile-doctor-curated` passes.

This folder is **peripheral** to product vision / ADR / backlog execution. It records per-campaign
triage (fix / suppress / skip) so cold sessions can see *why* a finding was acted on or left alone
— especially around crypto / keystore / proof-token code — without inventing `I-*` / `TB-*` / GitHub
issues per finding.
