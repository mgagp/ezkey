# Agent-surface review — step 0 framing (2026-11-23)

**Status:** accepted 2026-11-23. Hygiene pass, not a program: no `I-*` /
`TB-*`. Lane README: [`README.md`](README.md).
- **GitHub issue:** `#1472`

## Mission

Make a cold agent (Claude Code, Cursor, Copilot) productive on Ezkey from the first turn, with the
smallest always-loaded context that still prevents real mistakes. Shape the root guide as
**mission and compass → rules → what "done" means → how to prove it**. Everything else becomes a
pointer, a skill, a module guide, or a harness control (hook or permission).

Why: the startup context has grown by accretion (54 commits on `AGENTS.md` / `CLAUDE.md` /
`.cursor/rules` since 2026-08). Anthropic's guidance is that long instruction files lower
adherence. This is the same simplicity and accidental-complexity compass the product applies to
itself ([`design-principles.md`](../../design-principles.md) §1, §2, §9 *one canonical place per
concept*).

## Scope

**In:** root `CLAUDE.md`, root `AGENTS.md`, `.cursor/rules/*.mdc`, `.cursor/skills/*`,
`.claude/settings.json` and hooks, `.github/copilot-instructions.md`. Wave 2: module `AGENTS.md`
files.

**Non-goals:**

- Rewriting product canon (`product-intent.md`, design principles, methodology README, hygiene
  lane READMEs). The review moves pointers. It does not change decisions.
- Changing any hygiene lane's operating contract (HITL loops, tiers, cadence). Only where it is
  stored and when it loads.
- Dropping Cursor or Copilot support. Parity is a constraint.
- New tooling or frameworks.

## Success criteria (definition of done for this review)

1. **Budget (soft guardrail):** root guide ≤ **200 lines** (Anthropic's per-file target; from
   ≈ 900 lines always loaded today). Exceeding it blocks nothing: it triggers a prune pass. The
   per-line test (criterion 3) stays the real criterion; the number only reminds us to run it.
   Measured at the end of each wave. Cursor's always-applied set shrinks by the same moves.
2. **One home per concept:** zero rule stated in two always-loaded files. Mirrors are pointers or
   generated.
3. **Every remaining line passes the test** "would a cold agent make a real mistake without it,
   and would it not find this by reading the repo?". Each rule carries its *why* (one clause) and,
   where it is not universal, its trigger.
4. **Root guide has the four blocks:** mission and compass / rules / done / evidence, with the
   evidence ladder per touched surface (Java, Admin UI, API contract, mobile, docs-only).
5. **Skills are visible to both tools** from one location; every keyword lane is reachable as a
   skill; operator-only lanes use `disable-model-invocation: true`.
6. **No lane contract lost:** each moved section has a destination that a grep confirms, and
   every link resolves.
7. **Each PR leaves main coherent** (one wave per PR; no "lands with the next PR" coupling).

## Decision grid for step 3 (one section at a time, HITL)

| Decision | Use when |
|---|---|
| **Keep in root** | Universal, short, not discoverable from the repo, and a miss causes real damage. |
| **Skill** | Multi-step procedure or keyword lane used in a minority of sessions. |
| **Module guide** | Applies to one module or surface only. |
| **Platform file** | Windows-PowerShell, macOS or cloud-container only. |
| **Hook / permission** | Zero-exception rule that is mechanically checkable and repeatedly missed. |
| **Pointer only** | Canon exists elsewhere; the root keeps one line and a link. |
| **Delete** | Duplicate, stale, or discoverable from the code. |

## Operator decisions (2026-11-23)

1. **Skills location:** `.claude/skills/` becomes the single home (Cursor reads it).
2. **Always-applied `.mdc` that duplicate `AGENTS.md`:** remove them; `CLAUDE.md` stops importing
   them (Cursor reads `AGENTS.md` natively).
3. **Module guides for Claude:** one-line `CLAUDE.md` with `@AGENTS.md` per module, after wave 2
   trims the module guides.
4. **Copilot mirror:** no longer used. Extract any signal not already present in `AGENTS.md`,
   rules or skills, then retire `.github/copilot-instructions.md`.
5. **Budget:** soft guardrail of 200 lines for the root guide, not a gate (criterion 1). Dropped
   the 20 KB figure as redundant.
