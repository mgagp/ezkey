## Rationale (short)

Filled after each HITL turn — do not pre-authorize remediations in this open note.

### 1 - MOB-011

HITL briefing completed 2026-07-19: wizard sets local crypto/storage identity from server `enrollmentId` only; `installation` is UI/routing metadata and does not scope Keystore aliases or sealed-secret keys. Collision scenario (two Auth APIs both issuing enrollment `1` on one phone) accepted as clear.

**Next:** complementary analysis-design + mini Grill Me via ephemeral handoff
[`HANDOFF-mob-011-installation-scoped-identity.md`](../../backlog/handoffs/HANDOFF-mob-011-installation-scoped-identity.md).
Decision (fix / defer / suppress / skip) remains open until that session returns.

### 2 - MOB-012

HITL briefing completed 2026-07-19: `setUnlockedDeviceRequired(true)` from API 30 on enrollment EC and app seal keys with `setUserAuthenticationRequired(false)`, against Android’s Android 12–14 / “use only on 15+” warning (incl. auto-delete on lock-screen removal).

**Next:** short analysis / optional mini Grill Me via ephemeral handoff
[`HANDOFF-mob-012-unlocked-device-required-gate.md`](../../backlog/handoffs/HANDOFF-mob-012-unlocked-device-required-gate.md).
Decision (fix / defer / suppress / skip) remains open until that session returns.

### 3 - MOB-013

HITL briefing completed 2026-07-19: pending/respond call `ensureEnrollmentKeyPair` → native generate if alias missing, after server is already bound to the verify-time public key. Silent replacement cannot work and hides MOB-011/012 failures.

**Decision:** **fix**. **Implementation order:** MOB-011 → MOB-012 → MOB-013 (operator-confirmed).

Handoff: [`HANDOFF-mob-013-no-silent-key-ensure.md`](../../backlog/handoffs/HANDOFF-mob-013-no-silent-key-ensure.md).
Do not start MOB-013 coding until 011 and 012 are done on the branch.

### 4 - MOB-014

HITL briefing completed 2026-07-19: malformed pending HTTP 200 mapped to `undefined` like 204; Ed25519 fail-closed never reached when signature fields are stripped/empty.

**Decision:** **fix**. Independent of MOB-011→013 Keystore work; dedicated small PR preferred.

Handoff: [`HANDOFF-mob-014-malformed-pending-fail-closed.md`](../../backlog/handoffs/HANDOFF-mob-014-malformed-pending-fail-closed.md).

### 5 - MOB-015

HITL briefing completed 2026-07-19: `listEnrollments` broad catch → `[]`; missing sealed proof/integration key silently drops rows — crypto/storage failure looks like healthy empty.

**Decision:** **fix**. **UI display/recovery details not pre-authorized** — mini Grill Me + design clusters in the handoff must lock an UI contract table before Home (or other) UI work.

Handoff: [`HANDOFF-mob-015-broken-enrollment-list-visibility.md`](../../backlog/handoffs/HANDOFF-mob-015-broken-enrollment-list-visibility.md).
