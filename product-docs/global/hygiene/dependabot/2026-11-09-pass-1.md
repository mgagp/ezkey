`@babel/core` and `@babel/runtime` 8.0.10 → 8.1.0. `@babel/runtime` ships in the JS bundle
(Justin APK + Pixel). `@babel/core` is dev-only. The PR head `0d231dd2c0d9ee0461110b7d3d767c7144b22657`
had two commits: Dependabot's bump, then `github-actions[bot]` "regenerate third-party licenses
snapshot". All check runs on that SHA succeeded, including `ci-gate`. An owner `APPROVE` from
`mgagp` (2026-11-09T14:26:24Z, commit `0d231dd2`) did not clear `mergeStateStatus` BLOCKED.
`gh pr merge --squash --match-head-commit` without `--admin` was rejected: the base branch policy
prohibits the merge. The retry with `--admin` succeeded.

Ruleset `7558701` ("Basic protection") has `require_extra_approval_for_unattributed_changes: true`
and `required_approving_review_count: 0`. `--admin` skips branch rulesets, so **the ruleset was
bypassed**. The visible blocker matches the unattributed github-actions license commit, but this
pass cannot prove that clause was the only one still failing (a Cursor check suite was also queued
with zero runs). No later PR in this pass used `--admin`.
