## Lesson learned (discoverable rule)

- When replacing a deprecated constant, do **not** fallback to a raw numeric value (magic number).
- First check the library source/Javadoc deprecation note and migrate to the **named replacement**
  recommended by the maintainers (example in this pass: `HttpStatus.PAYLOAD_TOO_LARGE` →
  `HttpStatus.CONTENT_TOO_LARGE`).
